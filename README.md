
# Inventario de Electrónica - Universidad UPN

Este programa permite administrar el inventario de componentes electrónicos de la universidad.

Permite crear cuentas e iniciar sesión como estudiante o profesor.

Los usuarios pueden consultar los componentes disponibles, buscar componentes por su código, prestar componentes y registrar sus devoluciones.

Los profesores también pueden agregar nuevos componentes y eliminar componentes existentes.

El programa actualiza las cantidades disponibles cuando se presta o devuelve un componente.

La información del inventario y de los usuarios se guarda para conservar los datos al cerrar el programa.
